> **这本附录只做一件事**：让你能自己核对我说的每一句话。<br>
> **格式**：每条尽量给出【数值】【口径】【时点】【局限】【来源】，并标出 **A / B / C** 证据分级；不同小节因内容类型不同，列结构略有差异。<br>

```bash

git rev-list --count 276cbc0    # 官网   → 12

# 有提交的日历天数
git log --format=%ad --date=short | sort -u | wc -l

# 代码行数（按扩展名统计，排除 node_modules）
git ls-files | grep -E '\.(ts|tsx|js|jsx|py)$' | grep -v node_modules \
  | while read f; do wc -l < "$f"; done | awk '{s+=$1} END {print s}'
```

## A.8 一条关于数据的态度

这份清单里，有三件事我想让读者带走。

**第一，我把"未独立核实"的地方都标出来了。**

**第三，如果有一处我写错了，以原始来源为准。**

这本书里所有关键判断都尽量给了可点开的链接。**我宁愿你点开去看，也不想你只信我这一段话。**

# scripts/ —— 生成、校验与交付脚本

> **本目录只放脚本，不放内容。** 书的内容在 `parts/`（手写源）、`images/`、`svg/`。
> 所有脚本都锚定到**本目录的上一级**（= 书目录），因此**在任意目录下都能直接运行**，不受当前工作目录影响。
>
> 📌 **本文件是公开仓的适配版**：删去了内部工具链的绝对路径、私有协作流程与脱敏词表相关内容。若你是在别处看到这份说明，以本仓版本为准。

---

## 一、完整交付链（顺序不可调换）

```bash
cd <书目录>

# 0. 体例闸门：引用块内分行必须显式写 <br>（违规即非零退出，阻断交付）
python3 scripts/fix_hard_breaks.py --check

# 1. 合稿（parts/ → <书名>.md）
python3 scripts/build_book.py

# 2. 在线阅读版（<书名>.md + svg/ → <书名>.html，字体外链，体积小）
python3 scripts/build_html.py

# 2'. 下载版（同一份 md + svg，字体内嵌 base64，单文件离线可读，约 1.3 MB）
python3 scripts/build_html.py --embed-fonts

# 3. A4 PDF（Chrome 排版；**从离线版导出**，字形来源才可控）
python3 scripts/build_pdf.py --html "<书名>（离线版）.html" --out "<书名>.pdf"

# 4. 三层书签 + 元数据（对不上就报错，不猜页码）
python3 scripts/add_pdf_bookmarks.py "<书名>（离线版）.html" "<书名>.pdf"

# 5. 页码（**最后一步，每份 PDF 只跑一次**）
python3 scripts/stamp_page_numbers.py "<书名>.pdf"

# 6. 三形态正反探针（**改过正文用词时必跑**）：验证新文本已在「源分片 / 合稿 md / HTML / PDF」四面就位、旧文本已从四面消失
python3 scripts/probe_text.py . --new "新文本片段" --old "旧文本片段"
```

> 作者本人的完整链路里还有两步外部闸门（**不随本仓发布**）：合稿校验器（脱敏 / 体例 / 图号 / 附录编号等一整套机械校验）与配图几何闸门（检查 SVG 装饰条与宿主圆角是否吻合）。没有它们也能构建，只是少两道体检——所以**改过 `svg/` 之后，请务必人眼看一遍重渲的 PNG**。

**改了什么要重跑什么**：

| 改动 | 必须重跑 |
|---|---|
| 只改正文（`parts/`） | 0 → 1 → 2 → 2' → 3 → 4 → 5 → **6** |
| 只改配图（`svg/`） | 重渲 PNG → 2 → 2' → 3 → 4 → 5（阅读版/PDF 内联的是矢量源，不重跑就还是旧图） |
| 只改打印样式（`build_html.py` 的 `@media print`） | 2 → 2' → 3 → 4 → 5（**会改分页**，书签与页码必须重算） |
| 只改本 README 之类的说明文档 | **不必重跑** |
| 改字体（见 §四） | 2' → 3 → 4 → 5（**PDF 的字形来自内嵌字体**，换字体必须重出 PDF 并复核字体清单） |

> 页码只在链路里盖**一次**。要重盖 → 从第 3 步重跑整条链，不要在成品上再盖一遍（脚本会拒绝，见下）。

**⚠️ 重渲 PNG 的比例不是全库统一的**：内容图是 **2.2×**（1280×720 → 2816×1584），**封面是 1.4×**（1200×1800 → 1680×2520）。**比例必须从既有 PNG 的文件头尺寸反推**（`png_px ÷ svg_viewBox`），按统一比例硬渲会把封面压扁。另：pymupdf 读 PNG 会按 72dpi 重栅格化，**逐像素比对时不要用它读 PNG**（尺寸会变），用 PIL。

## 二、脚本清单

| 脚本 | 作用 | 输入 → 输出 |
|---|---|---|
| `fix_hard_breaks.py` | **体例闸门**。引用块内要分行必须行尾显式 `<br>`；否则 md 源码看着正常，渲染成 HTML/PDF 时四要素会被压成一段 | `parts/*.md` → 体检（或就地补标记） |
| `build_book.py` | **合稿**。按 `PLAN` 里写死的顺序把分片拼成主稿，并做一次双路复算（合稿结果必须等于各分片顺序拼接，任何漏拼都会当场断言失败） | `parts/*.md`（21 个分片） → `<书名>.md` |
| `build_html.py` | **构建阅读版**。markdown → HTML，把 `svg/*.svg` 逐个内联，重写可读锚点，生成目录与配图索引，套上阅读外壳。`--embed-fonts` 切到下载版（`@font-face` 用子集化 woff2 base64 内嵌） | `<书名>.md` + `svg/*.svg` → `<书名>.html` / `<书名>（离线版）.html` |
| `build_pdf.py` | **构建 A4 PDF**。Chrome headless 排版；页面尺寸/边距由 HTML 的 `@page` 决定，不在这里传 | `<书名>.html`（**建议传离线版**） → `<书名>.pdf` |
| `add_pdf_bookmarks.py` | **注入三层书签 + 元数据**。按字号带定位标题、与 HTML 标题清单**逐条比对**，对不上就报错退出 | `<书名>.html` + `.pdf` → 原地安全替换 |
| `stamp_page_numbers.py` | **盖页码**。Helvetica 9pt `#738599` 居中，跳过封面，封面之后重新起号 | `<书名>.pdf` → 原地安全替换 |
| `probe_text.py` | **三形态正反探针**。改过正文用词后，验证新文本在**四个面**（源分片 / 合稿 md / HTML / PDF）各就各位、旧文本已从四面消失。归一化**按形态分开**（只有 HTML 剥标签、还原实体；md 与 PDF 只去 `**` 与空白），并打印归一化前后的长度差 | 全形态产物 → 探针报告（退出码非 0 = 未落地） |

**换本书时要改的参数只有两处**：`build_book.py` 的 `PLAN`/`TITLE`（本书专属），`add_pdf_bookmarks.py` 的 `BANDS`/`COVER_PAGES`/`METADATA`（**必须用 `--probe` 重校，不能照抄**）。其余脚本都给路径参数或不依赖书名。

## 三、纪律（违反会静默出错）

1. **`parts/` 是唯一手写源。** `<书名>.md` 是合稿产物，**任何手改都会在下次合稿时丢失**。
2. **`images/` 与 `svg/` 必须同名成对**。PNG 给 md 用，SVG 给阅读版/PDF 内联；**改数据时改 SVG 重渲染，不要重画**。
3. **改了 SVG 就必须重跑 `build_html.py`**，否则阅读版与 PDF 里还是旧图。
4. **脚本不要用相对路径取文件。** 一律 `os.path.join(ROOT, ...)`，其中 `ROOT` 是「本脚本上一级」。这条曾经踩过：`build_book.py` 早期用裸相对路径，**只有在书目录下运行才不崩**。
5. **只使用免费商用字体**（见 §四）。换字体要重出 PDF 并复核字体清单——字体出问题是**不会报错**的那一类。
6. **页码脚本不幂等**：连跑两次会在**同一坐标叠两份文字**，渲染出来只是"略粗"，肉眼看不出来，但选中复制会得到 `63 63`。已加防呆——盖之前先扫页脚带，发现已盖即报错退出（`--force` 才允许强盖）。

## 四、依赖

- **Python 3.11+**（开发时为 3.13）
- 第三方库：`markdown`（构建阅读版）、`pymupdf`（渲染 SVG→PNG、书签、页码、页数统计；`probe_text.py` 只在扫 PDF 面时懒导入它）；**`fonttools` + `brotli`**（仅 `--embed-fonts` 子集化 woff2 时需要）
- **Chrome / Chromium**（`build_pdf.py` 自动探测常见路径）。**必须 `--no-sandbox`**，否则 `sandbox initialization failed`、退出码 133、产出空文件。
- **两种免费商用字体**（`--embed-fonts` 与 PDF 都要用）：
  - 中文 = **思源黑体 Source Han Sans CN**（Apache-2.0 / SIL OFL 1.1）
  - 等宽 = **JetBrains Mono**（SIL OFL 1.1）

  两者均须**安装到系统字体目录**（macOS 为 `~/Library/Fonts` 或 `/Library/Fonts`）；缺失时 `build_html.py --embed-fonts` 会明确报错并打印官方下载地址，**不会静默降级**。

## 五、九个已固化的坑（每条都对应脚本里的一段注释或断言）

| 坑 | 症状 | 处置 |
|---|---|---|
| **字号带照抄** | 换本书（或改了打印 CSS）后"PDF 抓到候选"条数 ≠ 标题数 → 拒绝写书签 | `add_pdf_bookmarks.py <html> <pdf> --probe` 重校 |
| **Chrome 子进程继承 stdout** | PDF 早就写好了（文件在长），命令却一直不返回（实测挂了 **3 分 45 秒**） | 输出落文件而非管道 + 独立进程组 + 收尾 `killpg` |
| **pymupdf 不能 save 回原件** | 原地覆盖报错；增量保存会把新旧内容叠起来 | 一律「临时文件 + 原子替换」 |
| **页码叠加** | 见纪律 6 | 防呆 + 链路只跑一次 |
| **网页操作提示被印进 PDF** | 第 1 页出现"点击任意配图可放大（Esc 关闭）…"这类**网页专属说明** | 打印样式里 `.hint{display:none}`（版本与口径说明条属于书的内容，保留） |
| **封面页数靠假定** | 封面 SVG 的副标题字号会落进标题带，制造假标题 | 实测「第 2 页第一行是不是第一个标题」，不假定 1 页 |
| **`build_pdf` 静默交付陈旧 PDF**（2026-09-20 实测） | "产物稳定"判定只看**磁盘上已有文件**体积连续两次不变，**不校验是不是本次写的**。Chrome 对 135 页要跑约 30 秒 > 3 秒判定窗 → 连续两次 build_pdf 都返回**上一轮的已盖章 PDF**，靠 `stamp_page_numbers` 的防呆才暴露 | 启动 Chrome **之前先 `unlink` 旧产物**——判定只能命中本次新写的文件 |
| **探针把"自己取错了文件"报成"改稿没落地"**（2026-09-22 实测） | `probe_text.py` 首版用"排除若干前缀"去 glob 根目录 `*.md`，**第一个命中的是 `README.md`** → 四个正向探针全部报"未落地"，看起来像改稿没落地。**判据换成"与 HTML 同名"**（三形态同名是目录契约） | 报"未落地"之前，先证明**不是自己取错了对象**；取文件不要用前缀排除法 |
| **归一化会删掉证据，把"已落地"报成"没落地"**（2026-09-21 实测） | PDF 正文里**合法**出现 `<`（表格格「2 天人工 + `<50 元 token`」），与后面的 `>` 配成"假标签"，一句剥标签正则**一口气吞掉 61,707 字符** → 四条正向探针全报 0 | 归一化**按形态分开**（HTML 才剥标签）；**必须打印归一化前后的长度差**，差了几万字符就是证据被删了 |

## 六、一个尚未实现的想法：把"每轮会变的数字"写回文档

交付链里缺两个脚本，列在这里是为了让目录契约提前留好位置：

| 脚本（不存在） | 设想的作用 |
|---|---|
| `stamp_arch.py` | 把架构说明里篇幅配比表的"实际总字符"重算写回 |
| `stamp_pdf_stats.py` | 把页数 / 书签数 / 体积 / 校验项数写回各说明文档 |

**为什么要设想它们**：这些数字每轮都变，**手写必然漂**——同一件事有两份，少动的那一份迟早对不上。一旦发现同一个数字在文档里出现两处以上，正确的做法是"重算写回"，而不是人肉对齐。
